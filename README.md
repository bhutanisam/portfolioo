# BHUTANISM :)

Hi, I'm Samriddhi, and this is my little corner of the internet.

I wanted to make a portfolio that felt more like me than a regular resume page. Different people know me for different things, so this is a mix of my work, interests, random facts and a few snapshots from my life. Basically, an introduction that got a little out of hand.

## What's inside?

- A bit about me (click the cards to unfold them)
- Some of my previous website work, including Novah Crochet and Kalora Shop
- The skills I'm currently learning
- A photo wall that opens pictures when you click on them
- A little facts section, because apparently the rest of the website wasn't enough

## Built with

HTML, CSS and vanilla JavaScript. No frameworks.

I used CSS Grid, Flexbox and media queries for the layout. JavaScript handles the mobile menu and interactive elements, while the expandable cards use HTML's built-in `details` element.

## Running it locally

Keep `index.html`, `style.css` and `script.js` in the same folder. Open `index.html` in your browser.

The homepage portrait is `me.jpg`, and the photo wall images go inside the `images/` folder. The Google Fonts used by the site need an internet connection.
