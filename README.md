# Internet Playground — portfolio template

A playful, responsive personal portfolio made with **HTML, CSS and vanilla JavaScript**. No framework, backend or build step.

## Before submitting
- Replace every `[PLACEHOLDER]` in `index.html` with your real content.
- Replace the portrait placeholder with your own image (e.g. `<img src="assets/me.jpg" alt="Portrait of me">`) and style it with `width:100%;height:100%;object-fit:cover`.
- Replace project preview placeholders with real screenshots and accurate project descriptions.
- Replace `href="#"` on project cards with real links. If no link exists, remove the arrow link instead.
- Replace `you@example.com` with your preferred public contact address.
- Only show client projects with permission; do not claim features or work you didn't do.
- Test on a phone and a laptop before submission.

## Features
1. Mobile menu that opens/closes and updates its accessibility state.
2. Project category filter using `data-category` attributes.
3. Random creative prompt selected from a JavaScript array.
4. Responsive layout via CSS media queries.

## How to run
Open `index.html` in a browser. Internet is needed only to load the Google Fonts; fallback fonts are included.

## How it works
- `index.html`: content and page structure.
- `style.css`: colours, layout, typography, responsive rules and decorative elements.
- `script.js`: three small interactions using `querySelector`, `addEventListener`, `classList`, `dataset` and `Math.random`.

## Deployment
1. Create a public GitHub repository and upload `index.html`, `style.css`, `script.js` and this README.
2. Repository Settings → Pages → Deploy from a branch → `main` / root → Save.
3. Wait for GitHub Pages to publish; test the live link.
4. Submit **both** the GitHub repository URL and live website URL.

The current content is intentionally sample text. Personalize it before submitting.
